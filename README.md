# StylerApp
Styler App


Here is the breakdown of the features categorized into MVP (Now) versus Post-MVP (Later):
MVP Features (Build Now)
 * Outfit Evaluation & Scoring: Assess current outfits using existing clothes and shoes to generate a style score.
 * Event-Specific Styling: Help users select and tailor outfits to train or dress for particular events.
 * Core Computer Vision / Segmentation: Utilize camera permissions to capture or upload photos, and automatically segment pieces of clothing from the image.
 * Wardrobe Substitutions: Suggest immediate substitutions from existing items that can raise the outfit's style score.
Post-MVP Features (Build Later)
 * Shopping & Purchasing Recommendations: Suggest external items and purchases to help users acquire missing pieces needed to reach target style scores.
